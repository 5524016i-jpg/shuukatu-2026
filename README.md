# シフト自動最適化・Excel出力ツール (ShiftScheduler)

Excelのシフト希望表を読み込み、曜日・繁忙期に応じた目標人数とスタッフ間の公平性（採用率）を考慮してシフトの自動割当・カットを行い、結果をExcelファイルへ出力するJavaアプリケーションです。

## 主な機能
- **Excelデータの読み込み・書き出し**: Apache POI を使用し、既存のExcelレイアウトを維持したままシフト結果を反映。
- **繁忙日・通常日の人数最適化**:
  - ピーク日（金・土・祝前日）: 目標 6名
  - 通常日: 目標 4名
- **公平性を考慮したシフト割当**: 希望日数に対する確定率（採用率）が低いスタッフを優先的に採用し、偏りを軽減。
- **集計サマリーシートの自動生成**: スタッフごとの希望日数・確定日数・カット日数・採用率（Excel数式）を別シートに自動出力。

## 使用技術
- Java 21
- Apache POI 5.2.3
